Home hero, version 3 (archived 2026-09-25): the axonometric opening.

hero-extrude.js as it was when ALOBI opened in an axonometric view on a
drafting grid (with a bounding box and corner brackets) and then turned down
into plan, in the manner of the McLaren brand film.

To use it again: copy this hero-extrude.js into the site root, replacing the
current one. It works with the current ShapeWaves.js and home-arrival.js.

The line field before any of this (version 2) is in archive/hero-v2-lines/.
