Home hero, version 2 (archived 2026-09-25): the fine vertical line field.

These are the files exactly as they were before the contour map and the
extruded ALOBI (hero-extrude.js) replaced the line field.

To go back:
  - Quick look without changing anything: open the home page with ?field=lines
    (for example http://127.0.0.1:5173/?field=lines). The live code still
    supports the line field.
  - To restore it for good: copy ShapeWaves.js, home-arrival.js,
    home-arrival.css and index.html from this folder back into the site root
    (replacing the current ones). hero-extrude.js can then be deleted.
